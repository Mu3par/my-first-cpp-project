#  Age Calculator App (C++)

A colorful and interactive Command Line Interface (CLI) application written in C++ that calculates your exact age in months, weeks, days, hours, minutes, and seconds!

##  Features
- **Accurate Calculations:** Uses `long long` data types to handle large number calculations without integer overflow.
- **Terminal Styling:** Built with ANSI escape codes for clean and colored output.
- **Clean Code:** Adheres to modern C++ conventions and standard code readability.

## 🛠️ Tech Stack
- **Language:** C++
- **Compiler:** `g++` (GCC)
- **Environment:** Linux (Fedora)
